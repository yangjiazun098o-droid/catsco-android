# CatsCo 移动端图标候选 · 2026-11-12

当前阶段是独立组件库探索，不是 Android 正式图标替换。

## 本轮约束

- 背景、原有前景与强调色、卡片、字号、描边样式沿用预览页现状。
- 修改图标内部的符号与构图。A/B/C 从同一功能分别选择视觉隐喻；D/E 根据用户提供的新参考建立完整的圆润轮廓与转折断笔两套规则。
- 符号识别与实际尺寸优先；不硬套黄金比例、螺旋或额外的 AI 装饰。
- 20 / 24 px 检查识别、留白和重心，72 px 放大检查接点。

## 构图修正与维护

- A 文件折角从约 4 格扩大到 8 格，保留三角形内部负空间。
- A/B 刷新用半径相等的 SVG 圆弧构造，不用手调 Bezier 模拟圆。
- 五套各有 36 个功能键，共 180 个标志；附件不再和新建任务共享键。不完整的方案会报错，不再静默回退。
- 源文件 `icon-geometry-source.cjs`，执行后更新 HTML 内联图形。HTML 页面保持自包含。
- `review-icon-geometry.cjs` 输出桌面、手机分组、重点图标截图与报告，检查缺失、图形边界、溢出、页面错误及筛选交互。
- 自动检查不判断功能是否易懂，截图审查与最终界面验收仍然必要。

构图方法参考：[IBM UI icons](https://www.ibm.com/design/language/iconography/ui-icons/design/)、[Fluent iconography](https://fluent2.microsoft.design/iconography)、[Material system icons](https://m2.material.io/design/iconography/system-icons.html)。本轮路径为预览自绘候选。

## D / E 新参考与规范

用户提供圆润图钉小图和开放式线性图标表作为直接参考。只学习构造规则，不认定原图来源和作者。

| 规则 | D 紧凑圆润 | E 转折断笔 |
| --- | --- | --- |
| 主画布 | 24 × 24，主体通常在 4–20 格 | 24 × 24，通常在 3–21 格 |
| 线宽 | 1.65，圆端、圆接点 | 1.5，平端、明确角点 |
| 轮廓 | 完整外形，圆肩与收腰 | 识别轮廓保留，在次要边缘断开 |
| 内部细节 | 简化至识别所需，避免小空心点 | 用短线和弧形回转表达特征 |
| 置顶 | 直立圆肩图钉 | 倾斜图钉，肩部断口与弧形收腰 |
| 文件 | 圆角文档，短行内容 | 底部弧形卷边文档 |
| 消息通知 | 圆肩铃铛 | 断开底线与弧形肩部的铃铛 |
| 账户 | 头肩轮廓 | 一条头部短线与肩弧 |

局部线宽例外：D 模型用量使用 2.4 格实线柱，避免窄空心柱在 20px 时堵塞。两套均沿用原 A 样本浅底和深色前景；没有新增品牌色。
